# MagicSMP GitHub Build Project

This compact version is designed for GitHub's browser uploader. The full `src/` tree is stored in `project-source.zip`, and GitHub Actions extracts it automatically before compiling.

## Build
1. Upload all files/folders in this directory to the root of a GitHub repository.
2. Commit the upload.
3. Open **Actions → Build MagicSMP → Run workflow**.
4. Download the **MagicSMP** artifact after a successful build.

Do not extract `project-source.zip` on GitHub; the workflow does that automatically.
